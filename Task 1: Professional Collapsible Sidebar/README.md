# Task 1: Professional Collapsible Sidebar

## 🎯 Task Requirements
- Build a collapsible sidebar that opens/closes with a button click
- Include logo placeholder and 4-5 navigation links with icons
- Smooth open/close animation
- **Bonus:** Fully responsive for all screen sizes

## 🎨 Color Palette (Specified)
- Sidebar Background: #FFFFFF
- Hover State: #F1F5F9
- Active State: #2563EB
- Text Color: #1E293B
- Border Color: #E2E8F0

## ✨ Features Implemented
- ✅ Smooth toggle animation (0.3s cubic-bezier)
- ✅ Logo with icon and text
- ✅ 5 navigation links with Font Awesome icons
- ✅ Active state highlighting
- ✅ Hover effects on all interactive elements
- ✅ User profile section for professionalism
- ✅ Responsive for all devices (mobile, tablet, desktop)

## 📱 Responsive Behavior
- **Desktop (>1024px):** Full sidebar (280px) with all content
- **Tablet (768px-1024px):** Collapsed sidebar (80px) with icons only
- **Mobile (<768px):** Hidden sidebar that slides in, with overlay

## 🚀 How to Use
1. Open `index.html` in any modern browser
2. Click the ☰ button to toggle sidebar
3. On mobile, click overlay or press ESC to close

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, Transitions, Media Queries)
- Vanilla JavaScript
- Font Awesome 6 (icons)
