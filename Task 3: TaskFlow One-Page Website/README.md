# Task 3: TaskFlow One-Page Website

## 🎯 Task Requirements
- Build a complete one-page website for a fictional app called "TaskFlow"
- Include sections:
  - Hero section with app name, message, and CTA button
  - Features section with 3 features (icons + descriptions)
  - Testimonials section with 2-3 user reviews
  - Pricing section with 3 options (Free, Pro, Team)
  - Footer with contact links and social media
- **Bonus:** Add scroll animations when sections appear

## 🎨 Design Specifications
- **Primary Color:** #2563EB (consistent with previous tasks)
- **Background:** #F8FAFC (light), #FFFFFF (white)
- **Text:** #1E293B (dark), #64748B (gray)
- **Accent:** #10B981 (success green)
- **Border:** #E2E8F0

## ✨ Features Implemented

### ✅ Core Requirements
- **Responsive Navigation Bar** with mobile menu

## 📱 Responsive Breakpoints

| Device | Breakpoint | Behavior |
|--------|------------|----------|
| Desktop | >1024px | Full layout, 3-column grids |
| Tablet | 768px - 1024px | 2-column features, stacked hero |
| Mobile | <768px | Single column, hamburger menu |
| Small Mobile | <480px | Optimized spacing and fonts |
