# Task 2: Professional Contact Form

## 🎯 Task Requirements
- Build a responsive contact form that looks good on all screen sizes
- Include: Full Name, Email Address, Subject, Message, and Submit button
- Clean layout with proper spacing
- **Bonus:** Add JavaScript validation (required fields, valid email format)

## 🎨 Design Specifications
- **Background:** #F8FAFC (page), #FFFFFF (form card)
- **Primary Color:** #2563EB (matching sidebar)
- **Text:** #1E293B (primary), #64748B (secondary)
- **Border:** #E2E8F0
- **Error:** #EF4444
- **Success:** #10B981

## ✨ Features Implemented
- ✅ Fully responsive design (mobile, tablet, desktop)
- ✅ Real-time validation with helpful error messages
- ✅ Email format validation
- ✅ Required field validation
- ✅ Character counter for message field
- ✅ Success message with animation
- ✅ Loading state during form submission
- ✅ Smooth hover and focus effects
- ✅ Contact information section

## 📱 Responsive Behavior
- **Desktop (>768px):** Full form with 3-column contact info
- **Mobile (<768px):** Stacked layout, full-width inputs
- **Small Mobile (<480px):** Optimized padding and font sizes

## 🔍 Validation Rules
- **Full Name:** Required, 2-50 characters, letters only
- **Email:** Required, valid format, <100 characters
- **Message:** Required, 10-1000 characters
- **Subject:** Optional (can be made required if needed)

## 🚀 How to Use
1. Open `index.html` in any modern browser
2. Fill out the form fields
3. Real-time validation shows errors as you type
4. Submit to see success message
5. Click "Send Another Message" to reset

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript (ES6+)
- Font Awesome 6 (icons)
